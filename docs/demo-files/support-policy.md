# Support Policy

## Response targets

| Priority | Example | Target |
| --- | --- | --- |
| P1 | App cannot start | Same day |
| P2 | Model fails to load | 1 business day |
| P3 | Question about settings | 3 business days |

## Local data

User documents, chat history, retrieval traces, and metrics stay on the local machine by default. Demo data can be deleted and reindexed without affecting installed model files.

## Demo Query

Ask: "What is the response target for a model loading issue?"
