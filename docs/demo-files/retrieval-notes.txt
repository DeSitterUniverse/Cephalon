Retrieval notes

The current retrieval pipeline combines dense vector search with SQLite FTS5 lexical search. Results are merged with reciprocal rank fusion and reranked with a Jina reranker running through ONNX Runtime.

Low scope uses fewer retrieved candidates for quick checks.
Medium scope uses the normal retrieval defaults.
High scope reviews a wider candidate set before answering.

The scope control changes retrieval breadth, not model intelligence.
