# Launch Notes

- Keep the library organized around source documents.
- Confirm the selected chat model is loaded before asking questions.
- Use Low retrieval for quick lookups, Medium retrieval for normal answers, and High retrieval when the answer needs broader evidence.
- Open Sources to inspect where an answer came from.
- Use Settings to confirm the ONNX embedder and reranker paths.
